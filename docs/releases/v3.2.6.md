# Tagvico AI v3.2.6

Tagvico 3.2.6 is a deployment-security and observability patch for stable v3.

## Highlights

- The bundled local Compose stack binds Paperless and Tagvico to loopback by
  default and keeps remote setup disabled.
- Trusted-LAN setup is an explicit, temporary opt-in with separate bind-address
  and setup controls.
- The Unraid template now defaults remote setup to off and pins the current
  stable image instead of the obsolete v2 alpha.
- The privacy-preserving aggregate telemetry receiver is deployed with D1
  retention, rate limits, and small-count suppression.
- Server-side monitoring can read the public aggregate summary without an
  Origin header while foreign browser origins remain rejected.

## Upgrade

Back up the `tagvico_ai_data` volume, pin
`ghcr.io/arturict/tagvico-ai:3.2.6`, and recreate only the Tagvico container.
This is a v3 patch and does not require a data migration.
