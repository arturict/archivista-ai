# Tagvico AI v3.2.0

Tagvico 3.2 replaces the parallel dark and light surfaces with one coherent
Paper & Pine interface across the application, landing page, and bundled
documentation.

## Highlights

- Home, Documents, Ask Tagvico, Organize tags, Activity, and Settings now map
  directly to the jobs users perform.
- Ask Tagvico shows its document and tag research, groups configured models by
  provider, and keeps every document or tag mutation behind an explicit
  approval.
- Duplicate-tag cleanup has a dedicated many-to-one review flow instead of a
  dense Settings control.
- Page-shaped skeletons preserve the expected layout while Home, Documents,
  Activity, and provider catalogs load.
- Document tags, provider controls, model metadata, buttons, and switches have
  stronger contrast throughout the light interface.
- The public landing page and versioned v3 documentation now use the same
  design, terminology, provider icons, and current product screenshots.

## Upgrade

Back up the `tagvico_ai_data` volume, pin
`ghcr.io/arturict/tagvico-ai:3.2.0`, and recreate only the Tagvico container.
Existing history, conversations, credentials, model choices, automation rules,
and recovery queues remain in the persistent volume.

This is a v3 update. It does not introduce a v4 migration or a parallel beta
theme.
