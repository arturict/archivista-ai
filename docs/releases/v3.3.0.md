# Tagvico AI v3.3.0

Tagvico 3.3.0 brings the household companion to Discord and lets first-run setup find Paperless-ngx on its own.

## Highlights

- New optional Discord companion bot with full Telegram parity: bounded
  document Q&A with cited originals, one-attachment uploads into Paperless,
  active-action listing, and approve/reject buttons for proposed changes.
- Every allowlisted Discord user is configured with their own Paperless token,
  so Paperless remains the permission authority. Foreign or replayed button
  interactions are rejected.
- The bot answers direct messages and, optionally, one home channel where only
  slash commands, mentions, and replies are processed — no privileged Message
  Content intent required. Conversation history stays in bounded process
  memory. The bot is off unless its environment variables are set.
- First-run setup gains **Scan for Paperless**: the wizard searches the
  attached networks for a running Paperless-ngx installation and fills the
  Base URL. Discovery derives its ranges from the machine's own interfaces,
  so a Tagvico container finds Paperless on the same Docker bridge.
- The public landing page now uses self-hosted, cookie-free analytics. The
  application, bundled docs, and installed containers remain telemetry-free
  apart from the existing opt-in aggregate reporting.

## Upgrade

Back up the `tagvico_ai_data` volume, pin
`ghcr.io/arturict/tagvico-ai:3.3.0`, and recreate only the Tagvico container.
This is a v3 minor release and does not require a data migration.
